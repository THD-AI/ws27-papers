# 7 · The standard decoder, matching, pairs fired checks along the cheapest lines

A program on an ordinary computer reads that film and decides which errors happened: the decoder. The standard one is called matching. It joins every fired check to another fired check, or to the edge. Each line stands for errors along it, and it picks the pairing with the cheapest lines, since a few errors are likelier than many. The costs come from the error model.
