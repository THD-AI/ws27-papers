# 3 · A logical qubit keeps its value in how its qubits relate

Ordinary computers protect a bit by storing it three times and taking a vote. A qubit can't be copied, that is no-cloning, and it can't be looked at without destroying it.

So the value is stored in how several qubits relate. This code turns a superposition of zero and one into a superposition of all zeroes and all ones. Alpha and beta stay the same. No single qubit holds the original state. The surface code does the same for flips and for phase errors, and every qubit in it still decoheres.

**A logical qubit keeps its value in how its qubits relate.**
